# Documentación Frontend - FoodPassApp

## Estructura del Código
- `src/components/`: Componentes reutilizables de UI (PlatilloCard, LoadingSpinner).
- `src/services/`: Capa de red con manejo centralizado de errores y expiración de sesión.
- `src/lang/`: Diccionario de internacionalización (i18n) en español.
- `src/screens/`: Vistas e interacción con estados de la interfaz.
